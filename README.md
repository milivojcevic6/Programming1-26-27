# Programiranje 1 26/27 - Repozitorij s Kodo za Vaje

Ta repozitorij vsebuje rešitve kode z vaj pri predmetu **Programiranje 1**, kot tudi dodatne naloge za samostojno vajo.

## 📁 Struktura Repozitorija

Koda je organizirana po skupinah in tednih vaj, dodana pa je tudi mapa z dodatnimi nalogami za trening:

```text
.
├── exercises/                  # Dodatne naloge za vajo
│   ├── week-1/
│   │   └── src/
│   │       ├── Tasks.java      # Naloge za reševanje
│   │       └── TasksSolved.java # Rešene naloge
│   ├── week-2/
│   └── ...
├── [ime-skupine]/              # Koda z vaj po skupinah
│   ├── tutorial-1/
│   │   └── src/
│   ├── tutorial-2/
│   └── ...
```

## 🧠 Dodatne Vaje (Trening)

Za dodatno utrjevanje znanja preverite mapo `exercises/`. V njej boste našli podmape za vsak teden (npr. `week-1`, `week-2`). Znotraj mape `src` posameznega tedna se nahajata:
- `Tasks.java` - Datoteka z nalogami, ki jih poskusite rešiti sami.
- `TasksSolved.java` - Datoteka s pravilnimi rešitvami za preverjanje vašega znanja.

# Programming 1 26/27 - Tutorial Code Repository

This repository contains code solutions from the tutorial weeks of the Programming 1 course, as well as extra practice exercises.

## 📁 Repository Structure

The code is organized by group and tutorial week, alongside a dedicated folder for extra training exercises:

```text
.
├── exercises/                  # Extra practice exercises
│   ├── week-1/
│   │   └── src/
│   │       ├── Tasks.java      # Unsolved tasks for practice
│   │       └── TasksSolved.java # Solved tasks for reference
│   ├── week-2/
│   └── ...
├── [group-name]/               # Group tutorial code
│   ├── tutorial-1/
│   │   └── src/
│   ├── tutorial-2/
│   └── ...
```

## 🧠 Extra Exercises (Training)

To solidify your knowledge, check the `exercises/` folder. Inside, you will find subdirectories for each week (e.g., `week-1`, `week-2`). Within the `src` directory of each week, there are two files:
- `Tasks.java` - A file containing exercises for you to solve on your own.
- `TasksSolved.java` - A file containing the correct solutions so you can check your work.
